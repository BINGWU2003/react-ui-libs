# Site logo

The site header (`components/BrandLogo.vue`) and favicon (`public/favicon/logo.svg`) use an original minimalist geometric Bento mark designed for `react-ui-libs`.

- **Metaphor**: Three precision-aligned modules forming a 20x20 grid (layout shell, styled component, and unstyled/headless primitive).
- **Theme adaptation**: The header mark inherits `currentColor`, and `logo.svg` adapts automatically to light (`#171717`) and dark (`#ededed`) browser color schemes via `prefers-color-scheme`.
